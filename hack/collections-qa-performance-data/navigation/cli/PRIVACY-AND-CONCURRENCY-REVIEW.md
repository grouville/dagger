# Diagnostic review

The instrumented and matched control CLIs both built successfully from 341595f376. A --help smoke passed with identical stdout and zero stderr, about 55 ms each (single smoke, not a performance claim). The numeric JSONL anchor/Main/Cobra/flush rows parsed correctly; no engine or Cloud calls were made. Runtime commands remain owned by the parent driver.

The phase helper's row buffer and dropped counter are mutex-protected. Each HTTP request has a separate locked numeric state; its terminal snapshot copies that state before publishing. sync.Once prevents duplicate rows from repeated response Close. Connect attempts are paired by their transient network/address keys; only duration/error/attempt totals are serialized. The phase records do not retain context, spans, requests, response bodies, URLs, headers or credentials. The end-of-process row snapshot is copied under lock and written afterward, avoiding export deadlocks or disk IO in transport hooks.

Transport hooks compose with any existing httptrace hooks. Authentication and sequenced-export metadata remain in their existing implementation; no transport instance, dial settings, retry policy or provider order changes. Request bodies are untouched. Response Read returns the original n/error and Close returns the original error; the observer merely counts bytes and error categories. The wrapper adds the usual diagnostic allocation/lock overhead and hides optional body interfaces such as WriterTo; the ordinary OTLP HTTP body read path uses Read/Close, but arbitrary exotic response body behavior is not a production compatibility claim. No pre-read, drain, compression experiment or endpoint rewrite is performed.

Counters never include error strings, status text, payloads, IDs or even transient connection keys. Events use fixed source-defined phase/category names. The outer file path is caller-selected and output remains mode 0600 in a task-owned directory; the driver uses a fresh file and mode 0700 output directory. Phase files are numeric diagnostic summaries, not raw OTLP captures.

Limits: once final flush snapshots the buffer, later events are not included. Normal provider shutdown drains before that point, but an analytics timeout can leave an HTTP operation unfinished; the missing row should not be mistaken for zero latency. A response never closed by its caller lacks its final HTTP row. Unusual nonnil-response-plus-error paths can also omit a completed-body row; original error/response behavior is preserved. Request ContentLength is declared length, not a count of bytes actually sent. Connection acquisition includes DNS/connect/TLS and is not a pure queue measurement; retries/multiple dials can overlap. Parent/child phases overlap and must not be summed.

No race test or fake-transport suite was run for this diagnostic during preparation; build and no-engine output/schema smoke are the completed checks. The shared checkout and retained engines were not modified.
