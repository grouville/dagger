Source-only revision after the preserved v1 harness failure. No additional fixture HTTP requests have been made. Native Git remote-curl.c check_smart_http accepts an exact service announcement, consumes its header section through flush, then parse_git_refs invokes discover_version on the remaining bytes. It also accepts a bare version-2 first packet. Native http-backend.c normally skips the banner when protocol_v2 is selected. The common pkt-line rules require receivers to normalize an optional LF. Capability keys use ALPHA (including uppercase), digits, hyphen and underscore; unknown keys are ignored.

The revised parser accepts these text/framing forms while retaining MIME checks, complete terminal flush, size/count bounds, malformed packet rejection and a known upload-pack command capability requirement. It will emit only a fixed framing enum (bare or service-prefixed, LF omitted/present) so another mismatch can be classified without retaining content. It does not authenticate repositories or turn responses into Dagger cache entries.
