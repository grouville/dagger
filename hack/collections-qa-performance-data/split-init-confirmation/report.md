# Split-init confirmation: 40 local commands

The confirmation does not reproduce the earlier artifact-listing increase: `list -a` is effectively flat, with three of six block-aligned observations lower and three higher. Fresh-comment check discovery is modestly lower in this series, while native file generation repeats its earlier improvement. This is additional prototype evidence, not a general no-regression or 500 ms discovery claim.

All 40 commands passed, with exact 14-row check output, ordered artifact rows and generated bytes verified. No Cloud calls or profiles were added. Fixtures, original engine and original heavy-init bytes were restored; the original engine remains stopped, its volume is preserved, and only the new temporary container was removed. Measured command intervals wrote 1,646,592 bytes, excluding startup and gaps.

Each block restarted its pinned engine, ran two counted exact listing primers, then three warm artifact listings, three unique-comment listings, one unique-input native generation and one unchanged check-listing control.
