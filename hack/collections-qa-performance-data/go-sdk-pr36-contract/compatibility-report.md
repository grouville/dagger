# Go SDK PR36: current API compatibility gate

The integration is **parked**, without a candidate performance result. The pinned PR36 source needs more than the JSON-dispatch compatibility adapter and two workspace SDK hooks. Removing legacy calls merely to make compilation pass would change module discovery and dependency-generation semantics.

The public source is `dagger/go-sdk` PR36 at `4dfd447d58344835a0d4692ec0c8e5683c18bd6f`. The earlier five template/dispatch validation gates passed; they did not validate the complete current workspace SDK interface. Two bounded engine proof attempts each stopped on call3, leaving four validated control calls and no validated candidate generation. Their original results and cleanup are archived separately.

| Boundary | Evidence | Required work before a new runtime proof |
| --- | --- | --- |
| Workspace SDK provider | `core/sdkmodule/provider.go:268` requires `findClientRoot(ws)` and `generateScope(ws,isModule,name,clients)`; PR36 lacks both. | Port the current SDK contract, including scope/root semantics. |
| SDK-managed module discovery | PR36 `go-sdk.dang` calls `CurrentModule.asSDK` in `modules` and `managedBase`. The current production schema has no such method. | Map SDK identity, configured scopes and module roots to the current workspace model; a mechanical rename is unproven. |
| Local dependency generation | PR36 `mod.dang:90` calls `ModuleSource.generateLocalDependencies`, absent from the current production schema. | Preserve dependency staging and authority under the current generation API. Skipping it is not a general equivalent implementation. |
| Local bridge syntax | Our unvalidated bridge applies `.length` directly to `ModuleSource.dependencies`. Dang requires an explicit projection first. | This is an error in our experimental bridge, not an upstream PR defect. No bridge correctness gate passed. |

The schema fixture was generated by the repository's real core schema installer and serializer, at the SDK's `v1.0.0-beta.11` view and the `v1.0.0` view. No API fields were fabricated. Its test passed. The full SDK contract gate then failed at compilation; root lookup, unsupported-scope guards and the negative interface witness did not reach their intended runtime boundary. The race step did not run. Cascading inference errors are not additional independent incompatibilities.

The frozen engine source also lacks the two obsolete core APIs. The schema proof used source HEAD `2088d5efed34ccff90829bec502320eeca579fc7`, with exact production file hashes in `recipe.json`; it did not use or launch a benchmark engine. This gate added zero engine, network or Cloud calls.

Static metadata remains a promising upstream direction. It cannot yet be credited with a discovery or edit-loop speedup on this fixture. API edits must still be compared with the existing TOML baseline's normal generation behavior; app/test-body edits must remain fresh; constructor cache policies must remain matched. The higher-priority independent experiments are module `baseAddress` and generic artifact metadata pruning.

The failing bridge and focused tests are retained unchanged for reproducibility. They are prototypes, not an adoption patch. Generated full schemas and raw test logs remain local; `schema-surface.json`, `diagnostics.json`, `validation.json` and the source/hash recipe are the shareable evidence.
