Each currently materializes an artifact selection ID and then performs a projection through `node(id:)`. A composed leaf can remove one intermediate request when the receiver has no memoized ID. These are request-count opportunities, not measured wall-time predictions, and not every command reaches every reader.

Use narrow SDK-internal projection methods and typed scalar DTOs, preserving the original selected query and its owning client. The pinned querybuilder already supports `SelectFields` and `SelectMixed`, so nested descriptions do not require raw selector access or a dependency change. Its `SelectWithAlias`/child construction gives a fresh node before argument mutation.

The generated `Artifacts.DimensionDefinitions` method currently requests IDs and returns lazy `ArtifactDimension` objects. Replacing the bulk CLI projection with that method followed by seven getters per result could introduce N-plus-one requests; it is not the desired implementation. Similarly, do not make `Ref.ID` return its input without validation as a global shortcut. `Ref` creates a lazy node query without filling the generated ID memo; direct projected fields preserve node/type validation at consumption.

Keep current sequencing for a first patch: strict load failures remain before execution, flags remain validated before binding, and global aliases remain global. Do not merge unrelated projections or speculative collection evaluation until their error-order and dependency contracts are explicit. A path can invoke dimension reading more than once for different scoped addresses; never replace that with an unscoped shared result.

Two additional ID-then-projection sites exist but should be separately reviewed: `listArtifactPaths` for unexpanded listings and `evaluateArtifacts` for `values(failFast:)`. The latter evaluates user code and needs stronger exactly-once/NEVER/PER_CALL and partial-result/fail-fast tests; it is not just a metadata reader. No implementation, build, benchmark or extra engine call was performed for these followups.
