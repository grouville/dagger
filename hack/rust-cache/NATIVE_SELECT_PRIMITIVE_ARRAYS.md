Internal primitive-array selection is a small standalone engine improvement. It removes substantial work from native-directory discovery, but it does **not** establish a listing speedup for the selected Go module. The broader source-snapshot module remains unselected.

`Server.Select` resolves a field normally and then copies its terminal list into a caller's slice. Previously it materialized a separate cache result for every string or number in that list.
