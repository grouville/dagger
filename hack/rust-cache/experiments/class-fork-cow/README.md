This experiment shares immutable class-definition maps and order slices between forks, then detaches storage before a branch mutates it. It preserves private class records, owners, locks, views, clients and receiver execution. Schema emission still runs. [Review and limits](../../NATIVE_CLASS_FORK_COW.md). [Prepared description](../../PR_CLASS_FORK_COW.md).

The review source is on `experiment/class-fork-copy-on-write`, stacked on the separate `fix/class-fork-history-isolation` branch. Both are pushed to the fork; no PR is opened. [Performance-only patch](change.patch). [Independent correctness regression](../class-fork-history-isolation/).

Read-only preparation with 128 added fields is 4.11 µs → 105 ns and 13,448 → 128 bytes, faster in all four component pairs. A fork followed by mutation is broadly flat and allocates 24 bytes more. The standard id field is also present. These component gains are not full-command multipliers.

The original test-edited listing cohort is 7.66 → 6.91 seconds, but faster in only 2/4 pairs under substantial host contention. A separate cohort admitted during quieter host periods is 6.74 → 6.55 seconds, faster in 3/4 pairs. Every test-edit pair allocates less, with cohort median paired savings of 202–239 MB. Source-only timing is mixed. No samples are discarded. Admission uses a 10% CPU-pressure threshold before a command; pressure can rise during it. This is not a cold-cache, restart, stock-engine or Rust-latency result, and it is not additive with earlier cohorts.

Both modes use the same new class layout, independent history fix, experimental engine and CLI. The switch isolates eager copying versus COW within that layout. All 48 timed commands have exact ordered rows and successful cleanup. Each workload initializes adding and removing a real test before four measured alternating pairs. Telemetry and ordinary GC remain; profilers are off in timings.

The archive includes all attempts, the original and fixed-baseline component cohorts, both full-command cohorts, standalone/current-main/development full DagQL race checks, 27 Go checks, 28 Rust cases and four comparative wcprof/CPU/allocation captures. Every comparative capture retains 800 getters, 804 module evaluations, 799 discovery hits and 1,415 SDK requests. Compressed wcprof chunks reconstruct byte-for-byte to the original full streams with no dropped events or open operations.
