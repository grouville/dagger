# span-resource-batches

See [the report](../../NATIVE_SPAN_RESOURCE_BATCHES.md). Complete-command observations and limitations take precedence over component speedups. No PR is opened.

Raw evidence, source variants, identities, reproduction drivers and restored state are retained. Large text captures are gzip-compressed; original and archived sizes and SHA-256s are in archive-manifest.json. Go files live under testdata to avoid introducing build packages. Executables and merged wcprof derivations are omitted with hashes; raw profiling chunks remain available. No databases, native snapshot contents or Git metadata are included. Drivers contain local absolute paths that must be adapted to reproduce elsewhere.
