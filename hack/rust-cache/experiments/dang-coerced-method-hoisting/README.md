# Typed method classification

The minimal Dang change recognizes typed methods through their type-checking wrappers, keeping them out of deferred variable initialization. Complete Go listing after a real test-file edit improves 14.31 → 12.71 seconds across four balanced pairs. Ordinary-source edits show no gain: 6.75 → 6.90 seconds. All 20 commands return correct rows and exit successfully.
